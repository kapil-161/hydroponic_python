1. PHOTOSYNTHESIS MODEL (8 equations)
File: src/models/photosynthesis_model.py
=====================================================

1.1 ARRHENIUS TEMPERATURE RESPONSE
Rate(T) = Rate_25 × exp(EA × (T_k - 298.15) / (298.15 × R × T_k))

Where:
- Rate(T) = Temperature-adjusted rate
- Rate_25 = Rate at 25°C reference
- EA = Activation energy (J/mol)
- T_k = Temperature in Kelvin
- R = Gas constant (8.314 J/mol/K)

1.2 RUBISCO-LIMITED PHOTOSYNTHESIS RATE (Ac)
Ac = Vcmax × (Ci - Γ*) / (Ci + Kc × (1 + O2_μmol/mol / Ko))

Where:
- Ac = Rubisco-limited assimilation rate (μmol CO2/m²/s)
- Vcmax = Maximum carboxylation rate (μmol/m²/s)
- Ci = Intercellular CO2 concentration (μmol/mol)
- Γ* = CO2 compensation point (μmol/mol)
- Kc = Michaelis constant for CO2 (μmol/mol)
- Ko = Michaelis constant for O2 (mmol/mol)
- O2 = Oxygen concentration (mmol/mol)

1.3 LIGHT RESPONSE FUNCTION (J)
J = (I2 + Jmax - √((I2 + Jmax)² - 4 × θ × I2 × Jmax)) / (2 × θ)

Where:
- J = Electron transport rate (μmol/m²/s)
- I2 = Absorbed photosynthetically active radiation
- Jmax = Maximum electron transport rate (μmol/m²/s)
- θ = Curvature factor (dimensionless, ~0.7)

1.4 LIGHT-LIMITED PHOTOSYNTHESIS RATE (Aj)
Aj = J × (Ci - Γ*) / (4 × (Ci + 2 × Γ*))

Where:
- Aj = Light-limited assimilation rate (μmol CO2/m²/s)
- J = Electron transport rate from equation 1.3

1.5 DAILY CARBON ASSIMILATION
A_daily = min(Ac, Aj) × photoperiod_seconds × 1.201e-5

Where:
- A_daily = Daily assimilation (g CO2/m²/day)
- min(Ac, Aj) = Limiting rate between Rubisco and light
- photoperiod_seconds = Daylight duration in seconds
- 1.201e-5 = Conversion factor (μmol CO2/s to g CO2/day)

1.6 LIGHT PENETRATION FACTOR
Light_penetration = 6.0 / LAI  [when LAI > 6.0]
Light_penetration = 1.0       [when LAI ≤ 6.0]

Where:
- Light_penetration = Factor for light distribution in canopy
- LAI = Leaf area index (m²/m²)

1.7 EFFECTIVE LEAF AREA INDEX
Effective_LAI = 6.0 + (LAI - 6.0) × 0.2  [when LAI > 6.0]
Effective_LAI = LAI                       [when LAI ≤ 6.0]

Where:
- Effective_LAI = LAI adjusted for self-shading effects

1.8 TOTAL CANOPY ASSIMILATION
Total_assimilation = A_daily × Effective_LAI

Where:
- Total_assimilation = Total daily CO2 assimilation (g CO2/day)

2.1 Q10 TEMPERATURE FACTOR
Factor = Q10^((T - T_ref) / 10)

Where:
- Factor = Temperature response factor
- Q10 = Temperature coefficient (~2.0 for biological processes)
- T = Current temperature (°C)
- T_ref = Reference temperature (°C)

2.2 AGE EFFECT ON RESPIRATION

Where:
- Age_factor = Age-related increase in respiration
- age_coefficient = Age sensitivity parameter (day⁻¹)
- age_days = Age of tissue (days)

2.3 NITROGEN EFFECT ON RESPIRATION

Where:
- N_factor = Nitrogen effect on respiration
- N_slope = Nitrogen sensitivity parameter
- N_ratio = Current N concentration / optimal N concentration

2.4 SIZE PENALTY FACTOR
Size_penalty = 1.0 + 0.02 × (biomass - 50.0)  [when biomass > 50g]
Size_penalty = 1.0                            [when biomass ≤ 50g]

Where:
- Size_penalty = Additional respiration for large plants
- biomass = Organ biomass (g)

2.5 MAINTENANCE RESPIRATION
R_maint = base_rate × biomass × temp_factor × age_factor × N_factor × tissue_factor × size_penalty

Where:
- R_maint = Maintenance respiration (g glucose/day)
- base_rate = Base respiration rate (g glucose/g biomass/day)
- tissue_factor = Tissue-specific multiplier

2.6 SIMPLE GROWTH RESPIRATION

Where:
- R_growth = Growth respiration (g CO2/day)
- glucose_required = Glucose needed for growth (g glucose/day)
- efficiency = Growth efficiency (dimensionless)
- 0.4 = Carbon fraction in glucose

2.7 GLUCOSE REQUIREMENT FOR GROWTH
Glucose_required = biosynthetic_cost × new_growth

Where:
- biosynthetic_cost = Glucose cost per unit growth (g glucose/g growth)
- new_growth = New biomass produced (g/day)

2.8 CARBON RESPIRED

Where:
- C_respired = Carbon lost to respiration (g C/day)
- glucose_respired = Glucose consumed in respiration (g/day)

2.9 TEMPERATURE ACCLIMATION

Where:
- T_ref_new = New reference temperature after acclimation
- T_ref_old = Previous reference temperature
- temp_diff = T_current - T_ref_old
- acclimation_rate = Rate of acclimation (dimensionless)

2.10 PROTEIN DENATURATION (HIGH TEMPERATURE)

Where:

2.11 DETAILED GROWTH RESPIRATION

2.12 DAMAGE RECOVERY RATE

Where:

- recovery_rate = Daily recovery rate

Stress = 0.3 × (T - T_opt_max) / (T_mild - T_opt_max)

Where:
- T_lethal = Lethal temperature threshold

5.4 BASE COLD STRESS (MILD)

- T_opt_min = Lower optimal temperature

5.5 BASE COLD STRESS (MODERATE)

- T = Current temperature (°C)
- T_base = Base temperature (°C)
- T_opt1 = Lower optimal temperature (°C)

6.2 THERMAL TIME (OPTIMAL RANGE)
TT = thermal_scale × (T - T_base)

Where:
- Applied when T_opt1 < T ≤ T_opt2

6.3 THERMAL TIME (LINEAR DECREASE)
TT = thermal_scale × factor × (T - T_base)

Where:
- factor = (T_max - T) / (T_max - T_opt2)
- T_max = Maximum temperature for development
- T_opt2 = Upper optimal temperature

6.4 TEMPERATURE FACTOR

Where:
- clamp = Constrain value between bounds
- max_TT = Maximum possible thermal time

6.6 STRESS ACCELERATION (WATER)

6.7 BOLTING RISK (PHOTOPERIOD)

- node_number = Current number of nodes

6.11 DEVELOPMENT RATE

Where:
- daily_TT = Daily thermal time accumulation

6.12 STAGE PROGRESS
