================================================================================
                          KEY DESIGN PATTERNS
================================================================================

• Event-Driven Architecture: Message bus for loose coupling
• Microservices: Each simulator is independent
• Dependency Injection: Parameters from CSV, not code
• State Pattern: Simulators maintain state, models are stateless
• Observer Pattern: Event subscriptions
• Strategy Pattern: Different execution modes (sequential/parallel/event-driven)
• Factory Pattern: Simulator creation
• Singleton Pattern: Global message bus

================================================================================
                          CIRCULAR DEPENDENCIES
================================================================================

The framework handles 31 circular dependencies through one-step lag:

    Biomass ←→ Photosynthesis ←→ Canopy ←→ Light
        ↕
    Roots ←→ Water ←→ Transpiration
        ↕
    Nitrogen ←→ Photosynthesis ←→ Growth

Solution: Dependency-ordered execution creates acceptable one-step lag
